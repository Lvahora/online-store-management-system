### 3.3. Отладка BUG-001: Неправильный расчёт суммы заказа
Симптом: Тест `CreateOrder_ValidRequest_ReturnsOrder` ожидает сумму 100000, получает 50000.

Гипотезы:
- А: Не учитывается `Quantity` в формуле расчёта
- Б: Неправильно передаётся `Quantity` из теста

Инструмент диагностики: Точка останова в `OrderService.CreateOrderAsync`, окно Watch.

Наблюдаемый факт: В строке `totalPrice += product.Price;` переменная `item.Quantity` не используется.

Исправление:

```bash
// Было:
totalPrice += product.Price;

// Стало:
totalPrice += product.Price * item.Quantity;
```

Регрессионный тест: `CreateOrder_ValidRequest_ReturnsOrder`проходит после исправления.

### 3.4. Отладка BUG-002: Ошибка в проверке остатков
Симптом: Тест CheckStock_SufficientStock_ReturnsTrue падает при запросе количества, равного остатку.
Гипотезы:
- А: Используется строгое неравенство > вместо >=
- Б: StockQuantity изменяется где-то ещё

Инструмент диагностики: Точка останова в ProductService.CheckStockAsync, логирование через ILogger.

Наблюдаемый факт: В логах: остаток 10, запрошено 10, результат False. Условие 10 > 10 возвращает false.

Исправление:

```bash
// Было:
var hasStock = product.StockQuantity > quantity;

// Стало:
var hasStock = product.StockQuantity >= quantity;
```
